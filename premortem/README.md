This is a specially adapted version of my **structured premortem** based on Gary Klein's research.

Simply install the premortem.skill file in Claude and ask for a premortem. 

Otherwise, it's automatic based on the description. When someone describes a concrete plan with real downside (a launch, hire, pricing change, strategic pivot), Claude recognises it fits the premortem skill's scope and loads it.
So they could say:

"Premortem this. We're moving to an SFr. 5000 annual subscription model."
"I'm launching a new product line next quarter. What could go wrong?"
"Help me stress-test this hire before we offer the role."

Or they could ask directly:

"Do a premortem on this plan."

The skill triggers automatically when the plan description matches the trigger criteria (concrete, specific, with downside risk). They don't need to know the skill exists or say the word "premortem" at all.
That said, the current description is fairly precise. If you find it's not triggering often enough, we can widen it to be more explicit: "Use this whenever the user is about to commit to something with downside — a launch, hire, pricing change, strategy pivot, anything where being wrong costs money or reputation" makes it more likely Claude will reach for it proactively.
